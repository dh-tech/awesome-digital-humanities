# AGENTS.md

This repository holds a curated Markdown list of digital-humanities tools. The list is `README.md`.
`CONTRIBUTING.md` is the only source for the contribution process. Read it before you change the list.

## Rules

- Run `npx awesome-lint` before each handoff. The command must pass.
- Add, edit, or remove one entry for each pull request.
- Keep the entries in alphabetical order.
- Update the table of contents when you add or remove a section.
- Open an approved Addition issue before you add a new resource. Edits and removals do not need one.
- Do not submit an issue or a pull request without human review.

## Writing

Write docs, commit messages, and pull request descriptions in Simplified Technical English.
Use Conventional Commits.
